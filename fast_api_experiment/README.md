# MLOps Lab - FastAPI and Flask Experiment

This repository contains experiments demonstrating API development using FastAPI and Flask.

## Files

app.py  
FastAPI application implementing a simple ML prediction API.

flask_app.py  
Simple Flask API example with a hello endpoint.

fastapi_hello.py  
Basic FastAPI endpoint demonstrating a simple GET request.
